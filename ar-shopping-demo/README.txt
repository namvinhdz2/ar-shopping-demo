NOVA AR STORE - DEMO NÂNG CAO

Tính năng:
- Website TMĐT responsive.
- Danh mục, tìm kiếm, lọc sản phẩm.
- Xem mô hình 3D, tự động xoay, đặt bằng AR.
- Đổi biến thể vật liệu nếu mô hình hỗ trợ.
- Chọn kích thước, số lượng, yêu thích.
- Giỏ hàng, tính tổng tiền, thanh toán mô phỏng.
- Lưu dữ liệu bằng localStorage.
- Hỗ trợ PWA với manifest và service worker.

Chạy trên máy tính:
1. Mở thư mục bằng Visual Studio Code.
2. Cài extension Live Server.
3. Nhấp phải index.html > Open with Live Server.

Chạy AR trên điện thoại:
1. Upload toàn bộ thư mục lên GitHub repository.
2. Bật Settings > Pages > Deploy from branch main/root.
3. Mở link HTTPS trên Chrome Android hoặc Safari iPhone.
4. Chọn sản phẩm > Xem 3D / AR > Đặt thử bằng AR.

Lưu ý: mô hình 3D được tải từ modelviewer.dev nên cần Internet.
