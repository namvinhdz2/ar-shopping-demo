# Nova AR Luxury

Phiên bản giao diện cao cấp, giữ nguyên ba sản phẩm hiện tại:
- Giày thể thao Nova Flex
- Robot trang trí Mini
- Tượng phi hành gia

## Cập nhật GitHub Pages
1. Giải nén ZIP.
2. Vào repository `ar-shopping-demo`.
3. Chọn **Add file → Upload files**.
4. Upload và ghi đè: `index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`.
5. Nhấn **Commit changes**.
6. Chờ 1–3 phút rồi mở lại GitHub Pages.
7. Nếu vẫn thấy bản cũ, mở tab ẩn danh hoặc xóa cache trình duyệt.
